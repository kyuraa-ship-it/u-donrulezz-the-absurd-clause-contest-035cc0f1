One original English sentence, phrased as a clause buried deep inside a terms-of-service agreement: deadpan legal boilerplate that quietly turns absurd.

> By using the Service, you grant us a perpetual, royalty-free licence to your shadow, including any future shadows, reflections, or silhouettes you may acquire.

## Run it

```sh
node main.ts
```

Writes the clause to `/output/entry.txt`.
